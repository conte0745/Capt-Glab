使い方ガイド

導入から、うまく撮れないときの対処までをまとめています。

導入手順

  1. Chromeウェブストアの CaptGrab のページを開きます。
  2. 「Chrome に追加」を押します。
  3. ツールバーのパズルのアイコンから、CaptGrab をピン留めしておくと、すぐに撮影できます。

ソースコードからビルドする場合

Node.js（20.19以上または22.12以上）、pnpm、Git が必要です。

  1. リポジトリを取得してビルドします。 
    git clone https://github.com/conte0745/Capt-Glab.git
cd Capt-Glab
pnpm install
pnpm build
  2. Chromeで chrome://extensions を開きます。
  3. 右上の「デベロッパー モード」をオンにします。
  4. 「パッケージ化されていない拡張機能を読み込む」から、生成された dist フォルダを選びます。

基本操作

  1. 撮りたいページをタブに表示します。
  2. ツールバーの CaptGrab のアイコンを押します。
  3. アイコンの下に「撮影中…」と表示され、撮影が始まります。
  4. 「保存してコピーしました」と表示されると完了です。表示は約2秒で閉じます。

画像はブラウザのダウンロード先に screen-0001.png の形式で保存され、クリップボードにもコピーされます。動作は設定で変更できます。ショートカットキーの初期設定は Alt + Shift + S（Macは Option + Shift + S）です。

設定

撮影時にアイコンの下に出る表示の歯車ボタンから、設定画面を開けます。アイコンを右クリックして「オプション」を選んでも開けます。変更はすぐに保存されます。

  • 撮影後の動作：ファイルに保存、クリップボードにコピー、別のタブで開く、から1つ以上選びます。
  • 保存先：ダウンロードフォルダ内のフォルダ名を指定します。毎回保存先を選ぶこともできます。Chromeの制限で、ダウンロードフォルダの外を固定の保存先にはできません。
  • 撮影するときの画面サイズ（ビューポート）：現在の表示サイズか、指定したサイズで撮影します。サイズを指定すると、撮影中にページのレイアウトが一時的に変わります。幅だけを変えるので、スマートフォン専用の表示になるとは限りません。
  • スクロールする領域：本文やサイドメニューだけがスクロールする画面で、最後まで撮るかを選べます。撮影中だけ領域を広げ、撮影後に元に戻します。
  • ファイル名の連番：次のファイル名を確認し、番号をリセットできます。
  • ショートカットキー：現在のキーを確認でき、Chromeの設定画面で変更できます。他の拡張機能と重なっていると割り当てられないことがあります。

別タブで開いた画像のショートカットキー

  • Ctrl + S（Macは Command + S）：設定の保存先に保存
  • Ctrl + Shift + S（Macは Command + Shift + S）：別名で保存
  • Ctrl + C（Macは Command + C）：クリップボードにコピー

制限事項

  • chrome:// などのブラウザ内部ページは撮影できません。
  • 長いページは、画像の長辺が16,000pxに収まるよう縮小して保存します。縮小したときはその旨を表示します。
  • 本文やサイドメニューだけがスクロールする画面は、設定に応じて領域を広げて撮影します。初期設定では本文だけを広げ、メニューは見えている部分を写します。iframeの中のスクロールは広げられません。サイトの作りによってはレイアウトが崩れたり、表示中の分しか読み込まない一覧が途中までになったりすることがあります。その場合は設定でオフにしてください。
  • 撮影範囲の横幅は表示中の幅までです。横にはみ出した部分は写りません。
  • スクロールして初めて読み込まれる画像は、読み込み前だと写らないことがあります。先にページを一度スクロールしてください。

よくある質問

「デバッグを開始しました」というバーが出ます。問題ありませんか？
デバッガ権限を使う拡張機能でChromeが表示する正常な動作です。バーは撮影後、数秒で消えます。バーが出ている間はページの表示が少し縮みますが、撮影結果には影響しません。
続けて撮影すると、時間がかかります。
同じタブでは、前回の撮影から約6秒経つまで次の撮影を待ちます。バーの表示中はタブの高さが縮んでいるため、消えてから正しい高さで撮るようにしています。サイズを指定している場合は待ちません。
「クリップボードにコピーできませんでした」と出ます。
撮影中に他の場所をクリックすると失敗することがあります。ファイルに保存する設定なら、画像はダウンロード先に保存されています。
「このページは撮影できません」と出ます。
chrome:// やChromeウェブストアなど、ブラウザが保護しているページは撮影できません。
「撮影できませんでした」と出ます。
他の拡張機能がタブを操作している場合は、その処理が終わってからお試しください。それ以外の場合は、ページを読み込み直してからお試しください。
「本文の見えていない部分は写っていません」と出ます。
設定の「本文を最後まで撮る」がオフのときや、広げられない作りのページで表示されます。設定をオンにしてお試しください。
「撮影中です」と出ます。
同じタブの撮影がまだ終わっていません。少し待ってからもう一度お試しください。
撮影中にデバッグのバーで「キャンセル」を押すと、ページの表示が崩れました。
撮影のために広げた領域は、30秒以内に自動で元に戻ります。すぐに戻すには、ページを読み込み直してください。
別のタブに表示した画像が消えました。
表示用の画像は保存していないため、再読み込みすると消えます。残したいときは、画面の「保存」を押すか、ショートカットキーを使ってください。
撮影した画像はどこかに送信されますか？
送信しません。詳しくはプライバシーポリシーをご覧ください。
