使い方ガイド

導入から、うまく撮れないときの対処までをまとめています。

導入手順

ソースコードからビルドして読み込みます。Node.js、pnpm、Git が必要です。

  1. リポジトリを取得してビルドします。 
    git clone https://github.com/conte0745/Capt-Glab.git
cd Capt-Glab
pnpm install
pnpm build
  2. Chromeで chrome://extensions を開きます。
  3. 右上の「デベロッパー モード」をオンにします。
  4. 「パッケージ化されていない拡張機能を読み込む」から、生成された dist フォルダを選びます。

基本操作

  1. 撮りたいページをタブに表示します。
  2. ツールバーの CaptGrab のアイコンを押します。
  3. 「作成中・・・」のウィンドウが開き、撮影が始まります。
  4. 「画像を保存しました」と表示されると完了です。ウィンドウは約2秒で閉じます。

画像はブラウザのダウンロード先に screen-0001.png の形式で保存され、クリップボードにもコピーされます。

連番のリセット

アイコンを右クリックして「オプション」を選ぶと、設定画面が開きます。「カウントをリセット」を押すと、次の画像は screen-0001.png に戻ります。

制限事項

  • ブラウザのズームが100%以外だと、レイアウトや下端が正しく写らないことがあります。100%に戻して撮影してください。
  • chrome:// などのブラウザ内部ページは撮影できません。
  • 撮影範囲の横幅は表示中の幅までです。横にはみ出した部分は写りません。
  • スクロールして初めて読み込まれる画像は、読み込み前だと写らないことがあります。先にページを一度スクロールしてください。

よくある質問

「デバッグを開始しました」というバーが出ます。問題ありませんか？
デバッガ権限を使う拡張機能でChromeが表示する正常な動作です。バーは撮影後、数秒で消えます。この間も撮影のレイアウトは固定されています。
続けて撮影すると、時間がかかります。
同じタブでは、前回の撮影から約6秒経つまで次の撮影を待ちます。バーの表示中はタブの高さが縮んでいるため、消えてから正しい高さで撮るようにしています。
「画像を保存しました（クリップボードへのコピーは失敗しました）」と出ます。
撮影中に別のウィンドウへ移動すると、コピーに失敗することがあります。画像ファイルは保存されているので、ダウンロード先から利用してください。
「キャプチャに失敗しました」と出ます。
ブラウザ内部ページなど、デバッガを接続できないページの可能性があります。また、他の拡張機能がタブにデバッガを接続していると失敗することがあります。その場合は、その拡張機能の処理が終わってから再度お試しください。
撮影した画像はどこかに送信されますか？
送信しません。詳しくはプライバシーポリシーをご覧ください。

サポート

不具合の報告やご要望は GitHub Issues で受け付けています。発生したページの種類とChromeのバージョンを添えていただくと、確認がスムーズです。
