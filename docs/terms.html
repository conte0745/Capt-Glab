利用規約

最終更新日：2026年11月17日

1. 適用

この利用規約（以下「本規約」）は、竹内涼矢（以下「運営者」）が提供する Chrome 拡張機能 CaptGrab（以下「本拡張機能」）と、その紹介サイトの利用に適用されます。本拡張機能をインストールまたは利用した時点で、本規約に同意したものとみなします。

個人情報と利用者のデータの取り扱いはプライバシーポリシーをご確認ください。有料機能の販売事業者、価格、支払方法などは特定商取引法に基づく表記に表示します。

2. 利用

本拡張機能は、パソコン版の Google Chrome で、表示中の Web ページを撮影するために利用できます。無料の機能は、アカウント登録なしで利用できます。

3. 撮影した画像

撮影した画像に写っている文章、画像、デザインなどの権利は、それぞれの権利者に帰属します。本拡張機能で撮影したことによって、運営者や利用者がその権利を得ることはありません。

撮影した画像の保存、共有、公開は、利用者の責任で行ってください。撮影するページの利用規約や、著作権、肖像権、プライバシーに配慮し、機密情報や個人情報が写っていないかを確認してください。

4. 禁止事項

本拡張機能の利用にあたって、次の行為を禁止します。

  • 法令や公序良俗に反する行為
  • 第三者の著作権、肖像権、プライバシーその他の権利を侵害する行為
  • 撮影するページの提供者が禁止している方法での撮影や利用
  • 本拡張機能や決済サービスの運営を妨げる行為
  • 不正な手段で有料機能の購入の手続きを行う行為

5. 有料機能

運営者が有料機能を提供する場合、その価格と支払方法は特定商取引法に基づく表記と、本拡張機能の設定画面に表示します。

  • 有料機能は買い切りです。一度購入すると、提供を終了するまで追加料金なしで利用できます。運営者が有料機能の提供を終了する場合は、購入済みの方への対応を含め、事前にこのサイトでお知らせします。
  • 購入の手続きと支払いは、決済サービスの ExtensionPay と Stripe で行います。支払いには、それぞれのサービスの規約が適用されます。
  • 購入後の返品とキャンセルの扱いは、特定商取引法に基づく表記をご確認ください。法令上認められる権利を制限するものではありません。不具合により有料機能が利用できない場合は、お問い合わせください。
  • 購入した有料機能は、購入時のメールアドレスで、別の Chrome に引き継げます。

6. ソースコード

本拡張機能のソースコードは GitHub で公開しています。ソースコードの利用、改変、再配布には、本規約ではなく MIT License が適用されます。

7. 変更と終了

運営者は、本拡張機能の内容を変更し、または提供を終了することがあります。有料機能の提供を終了する場合は、このサイトで事前にお知らせします。

8. 免責

運営者は、本拡張機能がすべての Web ページを正しく撮影できること、利用者の目的に適合すること、不具合がないことを保証しません。撮影できないページや、正しく写らないページがあります。

運営者が利用者に対して損害賠償責任を負う場合、その責任が運営者の軽過失によるときに限り、賠償の範囲は利用者に直接かつ通常生じた損害とし、有料機能を購入した利用者については、有料機能の購入代金を上限とします。運営者の故意または重大な過失による場合や、法令によりこの制限が認められない場合には、この制限は適用されません。

9. 規約の変更

運営者は、法令の改正や本拡張機能の変更などに応じて、本規約を変更することがあります。変更する場合は、変更後の内容と効力が生じる日を、このページで事前にお知らせします。利用者に大きな影響がある変更は、効力が生じるまでに十分な期間を設けます。変更後も利用を続ける場合は、変更後の規約が適用されます。変更に同意しない場合は、本拡張機能の利用を終了してください。

10. 準拠法と裁判管轄

本規約は日本法に従って解釈します。本拡張機能に関して紛争が生じた場合は、民事訴訟法の定めに従って管轄裁判所を定めます。

11. お問い合わせ

本規約についてのご質問は captgrab@shiftonton.net までお問い合わせください。
