Chrome拡張機能

見えているレイアウトのまま、 ページ全体を1枚に。

Capt Glabは、ビューポートを固定したままWebページ全体を撮影する拡張機能です。アイコンを押すだけで、PNGの保存とクリップボードへのコピーまで終わります。

導入手順を見る GitHub
  • アカウント登録不要
  • 画像を外部へ送信しない
  • 高DPIディスプレイの解像度で保存

押してから保存まで、操作は1回

撮影範囲の指定やスクロールは必要ありません。

  1. STEP 1 ・ 押す

    撮りたいタブでアイコンを押す

    小さなウィンドウが開き、撮影の進み具合を表示します。

  2. STEP 2 ・ 固定する

    今の表示サイズで固定して撮る

    幅と高さを押した時点のサイズに固定します。デバッグ中のバーが出ても、レイアウトは変わりません。

  3. STEP 3 ・ 残す

    PNG保存とコピーを同時に

    screen-0001.png のような連番でダウンロードし、クリップボードにもコピーします。

「きれいに全体を撮る」ための作り

ブラウザのデバッガ機能を使い、Chrome自身の描画結果を画像にします。

100vh のレイアウトを保つ

画面いっぱいのヒーローなど、表示領域を基準にした要素も表示中の高さのまま写ります。

つなぎ合わせない1枚撮り

スクロールしながら画像を重ねる方式ではないので、継ぎ目がありません。

高解像度のまま保存

Retinaなどの高DPIディスプレイでは、その倍率の解像度でPNGを出力します。

連番ファイル名

番号は自動で増えます。リセットは設定画面からいつでもできます。

画像は、あなたのPCから出ません

  • 撮影した画像はダウンロードとクリップボードにだけ渡します
  • 外部サーバーへの送信、アカウント登録、クラウド同期はありません
  • アナリティクスや広告はありません
  • デバッガ権限は、アイコンを押したタブの撮影にだけ使います
プライバシーポリシーを読む

導入前に知っておいてほしいこと

Capt Glabは、1クリックのページ全体キャプチャに絞ったツールです。

向いている使い方

  • Webページのデザイン確認やレビュー資料の作成
  • 画面の高さを基準にしたレイアウトの記録
  • 撮った画像をすぐチャットや資料に貼り付けたいとき

対応していないこと

  • ブラウザのズームが100%以外のページの正確な撮影
  • chrome:// など、デバッガを接続できないページ
  • 横にはみ出した部分の撮影、範囲指定、画像への書き込み
  • Chrome以外のブラウザでの動作確認
