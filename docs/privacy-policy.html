プライバシーポリシー

最終更新日：2026年10月31日

1. 利用目的

CaptGrab（以下「本拡張機能」）は、扱う情報をWebページの撮影、画像の保存、クリップボードへのコピーのためだけに使用します。広告、トラッキング、データの販売には使用しません。

2. 撮影時に扱う情報

ユーザーが拡張機能のアイコンを押すと、そのとき表示しているタブのページ全体を画像として取得します。画像には、ページに表示されている内容（氏名、メールアドレス、社内情報など）がそのまま含まれます。

撮影のために取得するのは、タブのサイズ、ページのレイアウト情報、撮影画像です。ページのURL、閲覧履歴、Cookie、フォームの入力値を個別に読み取ったり記録したりすることはありません。

3. 保存するデータ

  • 連番カウント：ファイル名の番号を決めるための数値を Chrome Storage（お使いのブラウザ内）に保存します。
  • 撮影画像：ブラウザのダウンロード機能でPNGファイルとして保存し、クリップボードにコピーします。本拡張機能の保存領域には残しません。

4. 通信

本拡張機能は、開発者や第三者のサーバーへ情報を送信しません。アナリティクス、利用状況やエラーの報告、クラウド同期も行いません。

5. 権限

権限 使用目的
debugger ビューポートの固定、ページサイズの取得、撮影に使用します。アイコンを押したタブにだけ接続し、撮影が終わると切断します。
clipboardWrite 撮影画像をクリップボードへコピーします。クリップボードの内容は読み取りません。
storage 連番カウントを保存します。

6. 保持と削除

連番カウントは、設定画面でリセットするか、本拡張機能をアンインストールすると削除されます。ダウンロードした画像とクリップボードの内容は本拡張機能の管理外です。ユーザー自身で削除してください。

7. 第三者への提供

ユーザーの情報を第三者に販売または提供しません。ユーザーデータの取り扱いは、Chrome ウェブストアのユーザーデータに関するポリシー（Limited Use の要件を含む）に従います。

撮影画像を他のサービスに貼り付けたりアップロードしたりした場合は、そのサービスのポリシーが適用されます。機密情報が写っていないか確認のうえ共有してください。

8. 変更と問い合わせ

機能やデータの取り扱いを変更する場合は、このページを更新します。ご質問は GitHub Issues で受け付けています。
